## Notes

- `BOOT_2K_COBRA_80K.bin` is the 80K "Standard BOOT (v.1)" image. cobrasov's disassembly of it is `BOOT_2K_COBRA_80K_updated.html` / `..._updated_compilable.asm` (there is no separate "updated" .bin on the site). The .bin carries a small patch at 07F0h-07F9h (sets 8255 PC7 = SO = BASIC EPROM A14, then RST 38h). The owner's К573РФ5 (`rom/dumps/K573RF5_boot80k_original.bin`, MD5 `c79c66140c44dc0346a823e96a31f0e2`) differs from this .bin in 22 bytes (see `docs/history.md`).
- `16K_UNIFIED_BOOT_rev.01.bin` is 12288 bytes (3000h) on purpose. The top 1000h bytes of the 16 KB image are unprogrammed. Layout: 0000h Boot Manager, 0800h 64K STD BOOT, 1000h 80K STD BOOT, 1800h HOMOK test, 2000h STD test, 2800h Mastery. The images are relocated copies, not byte-identical to the 2K files.
- `SYSTEM_ROM.bin` is 62283 bytes (F34Bh) on purpose, the rest of a 27512 is unprogrammed. Layout: 0000h OPUS v3.2, 4000h Spectrum BASIC, 8000h DEVIL (BASIC with floppy), C000h 80-column CP/M (80K boards only), F20Eh NMI routine. It is meant for a single 27512 BASIC EPROM, with the 16 KB section selected by SO (8255 PC7) on A14 and, on cobrasov v0.2 boards, TO (8255 PC3) on A15 (jumpers JP3/JP4).
- `CPM_Game_Loader.html` is the "CPM Game Loader" disassembly embedded on the boot page (iframe), kept because it documents the RST 38h / 0038h BASIC-loader entry that CP/M game loaders rely on.
- Disassemblies were made by the cobrasov.com author with dZ80 and annotated by hand. Lines ending `---@@@` are the ones patched for relocation in the Unified Boot.
